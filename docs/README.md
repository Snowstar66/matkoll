# Matkoll – underlag för Claude Code och BMAD

- `autonomi.md` – LÄS FÖRST: arbetsregler för autonomt bygge, standardval och när agenten får stanna och fråga.
- `brief.md` – produktbrief: vision, beslut, sju epics, datamodell, arkitektur, AI-upplägg, risker, lättviktig AAS-styrning och effektmål.
- `ux/ux-spec.md` – UX-specifikation med designtokens och skärmregler.
- `ux/skisser/` – fyra mobilskisser som referens (ej körbar kod).

Föreslagen start i BMAD: låt PM-agenten ta fram PRD från `brief.md`, och låt UX-steget utgå från `ux/`.
